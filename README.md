# 🎵 Maestro Studio

אפליקציית פרימיום לניהול מוזיקה, ניתוח מוזיקלי, יצירת דמויות — ו**דמות שמנגנת
את השיר בסינכרון מלא, עם אקורדים ותווים מדויקים פיזית**.

נבנתה על בסיס הסקיל [`music-motion-maestro`](../skills/music-motion-maestro).

## הפעלה

אין שלב בנייה ואין תלויות. פותחים את `index.html` בדפדפן:

```bash
# פשוט לפתוח את הקובץ
open maestro-studio/index.html

# או להגיש מקומית (מומלץ — מבטיח שנגן היוטיוב נטען תקין)
python3 -m http.server 8080 --directory maestro-studio
# ואז לגלוש ל־http://localhost:8080
```

הכול נשמר ב-`localStorage` של הדפדפן. יש ייצוא/ייבוא גיבוי במסך ההגדרות.

## מה יש בפנים

### 🎧 ספריית מוזיקה
קישורי יוטיוב קבועים, מסווגים לפי **ז׳אנר, אמן ואלבום**, עם עטיפות, חיפוש,
סינון וסרגל נגן — בסגנון Tidal. הקישור נשמר במערכת ומשמש גם לניגון וגם לניתוח.

### 📊 ניתוח מוזיקלי
לכל שיר נשמר ניתוח: **BPM, רשת ביטים, סולם, מבנה ואקורדים עם תזמון**.
שני מסלולים:

1. **ייבוא מהסקיל** — מריצים את צנרת הפייתון ומדביקים את ה-JSON:
   ```bash
   python scripts/fetch_audio.py "<YOUTUBE_URL>" --out work/
   python scripts/analyze_music.py work/audio.wav --out work/analysis.json
   python scripts/extract_chords.py work/audio.wav --beats work/analysis.json --out work/chords.json
   ```
   מזוהים אוטומטית: `bpm`, `key`, `beat_times`, `downbeats`, `sections`,
   `chords`, `cut_grid`.
2. **ניתוח מונחה בתוך האפליקציה** — הקשת קצב (tap tempo), בחירת סולם והזנת
   פרוגרסיה. הפרוגרסיה נפרסת על רשת הביטים לאורך כל השיר.

### 🎸🎹 הבמה החיה (גולת הכותרת)
דמות שמנגנת את השיר בזמן אמת:

- **יד שמאל על צוואר הגיטרה** בצורת האקורד הנכון — פוזיציה פתוחה ליד ה-nut,
  או **ברה** עם האצבע המורה בפרט הנכון. מספרי האצבעות מוצגים על הנקודות.
- **אצבעות על הקלידים הנכונים** בפסנתר — המשולש ביד ימין (אצבוע 1-3-5) והבס
  ביד שמאל, עם שמות הצלילים בעברית.
- **הזרועות פתורות ב-IK דו-עצמי**, כך שהושטת יד לפרט 1 ולפרט 8 מייצרת תנוחות
  שונות באמת — לא נפנוף משומר.
- **מרווחי הפרטים גיאומטריים נכון** לפי הכלל `d(n) = S · (1 − 2^(−n/12))`.
- **הגוף מתנדנד על הביט**, הפריטה סוחפת על המיתרים, והמעבר בין אקורדים נופל
  בדיוק ברגע שבו האקורד מתחלף.

### 🎭 דמויות ופרומפט-מאסטר
נועלים דמות פעם אחת (זהות, כלי, סגנון, פלטה, תאורה, עולם) ומשתמשים בה בכל שיר.
לכל דמות אפשר להפיק **פרומפט-מאסטר אחד שמכסה את כל הקליפ** — טבלת פאנלים עם
האקורד, מיקום הידיים ותנועת הגוף בכל פאנל. **אף פאנל לא חוצה החלפת אקורד**,
כי יד אחת יכולה להחזיק צורה אחת. הפרומפטים מותאמים ל-GPT/DALL·E, Gemini,
Midjourney (סטילס) ו-Sora/Veo/Kling/Runway (הנפשה).

### 🎓 שיעורים עם מורה מדבר
8 שיעורים לגיטרה ולפסנתר עם דיאגרמות אקורדים, טיפים, מטרונום, נגינת האקורד
בפועל (Web Audio) ו**הקראה בעברית** (Web Speech API) שמסבירה איזו אצבע על איזה
מיתר ובאיזה פרט. אם אין קול עברי מותקן, האפליקציה אומרת זאת ונופלת לקול ברירת
המחדל.

## מבנה

```
maestro-studio/
├── index.html
├── css/style.css          מערכת עיצוב (כהה, RTL, בסגנון Tidal)
└── js/
    ├── data.js            תורת מוזיקה, ספריית אקורדים+אצבוע, אחסון
    ├── analysis.js        בניית ציר זמן מוזיקלי (ייבוא/מונחה)
    ├── performer.js       הדמות המנגנת — SVG, IK, פריטבורד וקלידים
    ├── player.js          נגן יוטיוב + שעון מוחלק לסינכרון
    ├── characters.js      יוצר דמויות + מחולל פרומפט-מאסטר
    ├── lessons.js         שיעורים, דיבור, מטרונום, צלילים
    └── app.js             ניתוב, ממשק, וחיבור הכול
```

## הערות

- הווידאו של יוטיוב משמש כמקור **קול** בלבד ומוסתר; מה שרואים הוא הדמות על הבמה.
- ספריית האקורדים מכסה 24 משולשים (מז׳ור/מינור) + שביעיות נפוצות. אקורד שאינו
  בספרייה יוצג בשמו אך בלי צורת יד — כדי לא להראות אצבוע שגוי.
- נדרש חיבור רשת לנגן היוטיוב ולעטיפות. שאר האפליקציה עובדת גם אופליין.
