# תוכן מוכן לריפו MoneroGateway

תיקייה זו היא גיבוי של התוכן המלא המיועד לריפו `dudutal-dev/MoneroGateway`
(שחיבורו לסשן ממתין לאישור). התוכן כבר עבר קומיט מקומי ובדיקת דפדפן.

מה בפנים:
- `index.html` — אפליקציית Gateway Process עם הספר המורחב: **20 פרקים**
  (13 המקוריים + פרקי ההרחבה 14–20 משולבים במערך BOOK), תיקוני מזהי CREST,
  ועדכון מוני הפרקים. נבדק ב-Chromium: הפרקים נטענים, c14 נפתח, ללא שגיאות JS.
- `sw.js` — גרסת cache חדשה (gateway-2026.08.11-b31-ext20).
- `README.md` — מעודכן למהדורה המורחבת.
- `LICENSE` — MIT.

להשלמת הפריסה לריפו MoneroGateway יש להוסיף לצד הקבצים:
1. את תיקיית `gateway-research/` (נמצאת בשורש הענף הזה).
2. את `gateway-research-book.pdf` מריפו Gateway המקורי (לא נכלל כאן כדי לא
   לשכפל קובץ בינארי; הכפתור באפליקציה מצפה לו בשורש).
